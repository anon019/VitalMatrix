# Mini Program 0.3.6

## 用户可见变化

- 饮食详情页将热量、宏量营养、综合评分和本餐结论收敛到一个概览区，减少重复卡片和无效滚动。
- 识别结果、营养分析、健康洞察和未来 24 小时建议形成更清晰的长页节奏。
- 未来三餐使用稳定的早餐、午餐、晚餐或加餐短标签，完整菜单标题在内容区自然换行。
- 菜品以编号清单展示；后端未返回食材和做法时，每个餐次只显示一条说明，不再每道菜重复空状态。
- 餐食照片失效后收起大块空白图片区，使用紧凑占位说明，核心营养数据仍可正常阅读。
- 主页、趋势、饮食、AI 和设置页统一了区块标题、卡片间距、按压反馈、空状态和用户向文案。

## 兼容性

- 保留两阶段饮食分析、2 秒建议轮询、90 秒上限、建议单独重试、上传防重和超时记录找回。
- 保留后端已返回的全部餐次、菜品、份量、营养值、风味、体验描述与搭配原因。
- 保留海报生成、完整滚动、保存、403 刷新与确认后强制重生成。

## 验证

- JavaScript 语法、JSON 解析、WXSS 花括号、WXML 结构检查与 `git diff --check` 通过。
- 开发者工具在工具令牌过期前已用真实晚餐数据热更新新的概览、分区标题、菜品编号、餐次短标签和缺失菜谱说明。
- 开发者工具重启模拟器时账号令牌过期，工具报 `INVALID_LOGIN, access_token expired`；这是工具登录状态，六页全量回归需在重新登录后补做。
