# v0.3.2 Release Notes

Release date: 2026-08-21

## Summary

This release completes a visual and interaction refinement across all six mini program pages while preserving the backend contract work from v0.3.1.

## Highlights

- The dashboard's lower data sections now share the same restrained green, white, and gray-green system as the redesigned first screen.
- Trends use five focused categories. Nutrition metrics render one per row, and inactive chart groups are removed from the live view tree.
- Seven-day heart-rate detail is requested only when the sleep category is opened.
- Nutrition capture and daily summary use compact controls, a single green action, and consistent loading skeletons.
- Nutrition detail keeps all current analysis, multi-meal recommendations, poster preview, save, and regeneration behavior with a clearer visual hierarchy.
- AI guidance is now a light, data-oriented health interface without purple starfields, glow effects, or decorative continuous animation.
- Settings has a clearer profile/device layout and recovers correctly when login restoration finishes after the page is created.

## Compatibility

- No backend endpoint or response-field adaptation was removed.
- Signed meal images, multi-meal recommendations, poster caching, save, retry, and 403 recovery paths remain intact.
- Existing dashboard calculations and cache behavior are preserved.

## Verification

- All JavaScript files passed `node --check`; JSON parsing, WXSS brace checks, and `git diff --check` passed.
- WeChat DevTools compiled with zero build errors and zero build warnings.
- Dashboard, trends, nutrition, nutrition detail, AI, and settings were inspected with live data.
- The trends nutrition layout and category replacement behavior were verified on iPhone 15 Pro Max and iPhone 6/7/8 simulators.
- Historical meal-image 404s remain backend media-object issues and continue to fall back to the existing stable placeholder.

## Versioning

- App version: `0.3.2`
- Recommended Git tag: `miniprogram-v0.3.2`
