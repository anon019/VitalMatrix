# Mini Program 0.3.7

## 用户可见变化

- 图片识别完成后，本餐核心结果立即可看；未来饮食建议在详情页按 2 秒节奏独立更新，完成后自动刷新为最终内容。
- 推荐菜谱的食材改为可自动换行的标签列表，做法改为从 1 开始的逐条步骤，长内容更容易阅读。
- 历史餐食图片失效时显示“历史图片不可用”，营养分析与饮食建议仍可继续查看。

## 稳定性

- 建议完成时若已有详情请求在途，会先等待其结束，再强制获取一次最终详情，避免竞态遗漏最新建议。
- 餐食列表对单条失效缩略图做页面内熔断；详情页对失效大图做当前记录熔断，不再通过自动刷新反复请求同一个 404 资源。
- 保留上传防重复、90 秒轮询上限、页面隐藏与卸载清理、建议单独重试及海报 403 恢复逻辑。

## 验证

- 状态机冒烟测试确认首次轮询为 2000ms，`completed` 后使用 `force: true, silent: true` 刷新详情。
- 菜谱归一化测试确认逗号、顿号、换行、箭头、分号和已有编号可拆为独立食材或步骤。
- 历史图片测试确认同一记录连续两次错误仅产生一次占位更新，且不调用列表或详情刷新。
- JavaScript 语法、WXML 容器闭合、WXSS 花括号与 `git diff --check` 通过；开发者工具因登录令牌过期尚未补做渲染回归。
