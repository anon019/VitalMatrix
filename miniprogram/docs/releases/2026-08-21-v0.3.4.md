# v0.3.4 Release Notes

Release date: 2026-08-21

## Summary

This release restores the complete trends experience and the richer Natural Table nutrition UI after the previous visual simplification made important content harder to discover.

## Highlights

- Nutrition, Polar training, Oura sleep, activity, and recovery trends are all rendered on one continuous page again.
- A compact trend index provides fast jumps to each section without replacing or unmounting any other trend group.
- Nutrition trend metrics remain full-width, preserving the readability improvement requested for the seven-day series.
- The nutrition page regains its warm organic palette, decorative background, meal-time emojis, animated steaming-bowl loader, colorful macro indicators, and expressive empty states.
- The v0.3.3 two-stage image upload, immediate core analysis, background recommendation polling, recommendation-only retry, timeout recovery, and duplicate-request protection remain unchanged.

## Verification

- JavaScript syntax, target WXML structure, WXSS braces, and `git diff --check` passed.
- WeChat DevTools rendered all five trend groups in the same page tree.
- The sleep shortcut scrolled directly to live Oura sleep-score, duration, and deep-sleep charts.
- The restored nutrition page displayed all four meal emojis, current nutrition summary, rich meal cards, and backend-provided ratings.
- WeChat DevTools reported zero workspace problems and zero debugger errors after the final compile; remaining warnings are simulator/runtime notices.

- App version: `0.3.4`
