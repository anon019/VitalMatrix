# Mini Program 0.3.10

## Summary

This release polishes the most visible UI regressions without rebuilding the mini program or changing the two-stage nutrition workflow. It restores readable AI and settings headers, fixes macro-rating alignment, makes health goals real server-backed settings, and corrects the oversized settings tab icon.

## UI changes

- AI uses a high-contrast deep-green hero with a restrained grid texture, one-time core entrance motion, and friendly nutrition, recovery, activity, and knowledge symbols.
- Settings uses the same high-contrast header language and clearer card hierarchy.
- Nutrition analysis uses fixed-height rating capsules with semantic green, amber, and red states instead of text backgrounds whose position depended on line height.
- The settings gear now occupies the same perceived area as the other four tab icons.

## Settings behavior

- `health_goal` and `training_plan` are read from `/api/v1/user/profile`.
- Users can edit both values and save them through `PUT /api/v1/user/profile`.
- The backend already consumes these fields when building AI recommendation and nutrition-analysis context, so the card now reflects actual behavior instead of static copy.

## Verification

- WeChat DevTools: live AI recommendation data remained visible after the visual update.
- WeChat DevTools: the settings page displayed the saved server goal, entered edit mode, and kept the remaining profile and Polar data intact.
- WeChat DevTools: the latest dinner showed aligned “适中”, “充足”, and “偏高” capsules in the nutrition-analysis card.
- Static checks: JavaScript syntax, JSON parsing, WXSS structure, and `git diff --check`.

## Known external issue

Historical object-storage meal images still return server-side 404 responses for missing legacy files. The existing “历史图片不可用” fallback remains in place and is unrelated to this UI release.
