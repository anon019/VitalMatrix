用户立即得到什么

  • • 上传成功后立即结束全局 Loading
  • • 食物明细、热量和宏量营养马上可见
  • • 未来三餐只在建议区域显示独立进度
  • • 建议失败或超时不会把整餐标记为失败

状态与缓存

  • • 每 2 秒请求一次无缓存状态接口
  • • 90 秒后停止前台轮询，服务端继续处理
  • • completed 清缓存并强制拉取最终详情
  • • 页面隐藏和销毁时必须清理定时器

重试边界

  • • 上传超时先查记录，绝不自动重传图片
  • • 推荐失败只调用 recommendations 接口
  • • 海报 403 只刷新签名 URL，不强制重生成
  • • force=true 只由用户明确确认后触发
