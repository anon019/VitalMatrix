# 个人健康数据集提交与公开同步

日期：2026-10-16。

## 范围

本轮只提交个人健康数据集相关的后端、迁移、测试和接入文档。工作区其他模型、营养超时及架构图改动保留原状，未纳入本轮。

- 来源记录、结构化健康日志、每日研究特征和待整理日期队列。
- 原始数据变更后的自动重算，来源证据、单位、缺失值和质量标记。
- Oura session、身体资料快照及渠道状态，Polar 补充维度和接口修正。
- 登录 JWT 健康日志录入，以及密钥保护的只读 REST / Streamable HTTP MCP 研究工具。
- 服务接入文档、Mac 前端契约、小程序分批实施清单及可复制 prompt。

小程序第一批负责连接管理、数据质量、结构化补录和饮食完整确认；设备同步和数据整理在后端执行，不依赖前端发布。此次不发布小程序或 Web 前端。

## 验证依据

- 实现阶段后端 96 项测试通过，包含隔离 PostgreSQL 的迁移触发器、事务回滚、跨日修正、并发队列和饮食确认失效测试。
- Oura 授权补采阶段，Oura 客户端及研究数据相关 22 项测试通过。
- 本轮文档整理和提交不重复运行上述测试；同步前检查提交范围、文档链接、空白错误与公开文件中的敏感内容。

## 公开版本边界

遵循 [公开仓库同步标准](public-repo-sync-standard.md)，目标为已有公开仓库 [VitalMatrix](https://github.com/anon019/VitalMatrix)。本地工作仓库 origin 不变。

公开版本通过临时克隆中的专用同步分支生成，仅同步本轮批准的文件与文档入口；保留公开仓库已有配置模板。移除个人数据盘点、实际设备授权结果、个人数据数量和日期覆盖；不上传环境文件、密钥、用户数据、媒体、机器路径或实际部署域名。

本地后端和文档分别使用 Conventional Commits 提交。公开版本也分开提交，使用 GitHub no-reply 身份；先推同步分支，再 fast-forward 更新 main，确认成功后删除远程同步分支。具体提交号以 Git 历史为准。
