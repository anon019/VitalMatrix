VitalMatrix / Architecture

Personal Health Intelligence Platform

A single FastAPI core connects browser and agent clients to health integrations, staged AI workflows, private media, and operational data services.
CURRENT · 2026-08-22

ONE CORE, THREE CLIENTS

Web, Mini Program, and MCP clients share the same authenticated service contracts and health data model.

STAGED AI WORKFLOWS

Structured analysis, recommendation, and poster rendering are separate bounded stages with persistence between them.

PRIVATE BY DEFAULT

Health records and uploaded media stay behind application authorization; public access uses short-lived signed routes.
